Online Voting System
🎯 Project Objective:
To build a secure, user-friendly online voting platform where an admin manages elections, voters can securely log in, and cast votes anonymously, ensuring election integrity and accessibility.

🔑 Key Features:
Admin Panel: 
Create and manage elections (e.g., local, organizational)
Add and manage candidates for each election
Register and approve eligible voters
View election results after voting closes

Voter Registration and Authentication:
Voters sign up with voter ID or username/password
Profile details stored securely

Voting Interface:
Show active elections available to the logged-in voter
Display candidate list with details and photos
Allow each voter to cast a single vote per election
Confirmation before final submission

Vote Anonymity & Security:
Votes stored anonymously in the database
Prevent double voting using flags or token verification
Use encrypted connections (HTTPS)
Result Tally and Display
Automatically tally votes when election closes
Display live or final results (based on election settings)


Accessibility Features:
Simple UI/UX suitable for elderly and disabled
Screen reader friendly, large fonts, and easy navigation
